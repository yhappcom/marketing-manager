## Latest validated addition — 184
Search Console query rows are evidence, not a complete vocabulary census. Rare/anonymized queries are privacy-protected; visible query rows can therefore sum to less than overall Search totals, and query filtering changes what remains observable. Search Analytics extraction also has row/coverage constraints. For sparse professional demand, a missing visible query must never be interpreted as zero demand.

CV0–CV5: `property/time identity → aggregation identity → privacy/coverage identity → canonical/index identity → decision sufficiency → downstream-value validation`.

Preserve: `no visible query row ≠ zero demand`, `visible-query sum ≠ necessarily total demand`, `property aggregation ≠ page aggregation`, `reported URL ≠ necessarily originally requested URL`, `impression ≠ visit`, `click ≠ qualified visitor`, and `Search traffic ≠ install/retained value`. Reconcile desired/declared/Google-selected canonical/reporting URL before diagnosing a page as demandless. BigQuery bulk export may quantify anonymized aggregate demand without exposing protected query text, but it is optional for small properties and must not create cloud spend merely for curiosity.

## Progress interpretation
Zero-cost success is not page count, rankings, clicks, followers, karma, submissions, pre-registrations, pre-orders or installs. Store conversion and web traffic are not terminal objectives. Platform Store/Search objects retain native semantics even when normalized to common intent/value layers. Underpowered experiments do not become useful because a platform permits them. Pre-order/pre-registration creates a finite platform commitment/delivery window. Reddit promotion is governed per community; permission does not guarantee reachability, and owning a community does not create a right to mobilize its members into third-party communities. Owned-web publishing must serve distinct specialist demand rather than manufacture query coverage. Search Console visible queries are privacy-filtered/coverage-limited evidence rather than a complete demand census. Sparse, suppressed, anonymized, filtered, inconclusive or unattributed evidence is not zero. Sustainable growth requires qualified users to reach and repeat the product value promised by acquisition surfaces while advertising contributes reconciled incremental revenue only from privacy-eligible, non-intrusive states.
