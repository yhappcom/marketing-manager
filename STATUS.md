## Latest validated addition — 205
Owned HTTPS routes are now treated as acquisition/reactivation continuity infrastructure rather than merely technical deep links. Apple Universal Links and verified Android App Links can preserve one owned URL across installed-app and web-fallback states. Android 15+ Dynamic App Links add server-side path/query/fragment/exclusion refinement without an app release, but dynamic rules cannot expand manifest scope and Android ≤14 does not apply the Android-15 dynamic path/exclusion behavior.

Route handling remains distinct from attribution. Apple campaign tokens, Google UTM/source credit, browser/referrer observations, app opens and downstream specialist-value completion are separate evidence. A route is not successful merely because it opens the app.

DQ0–DQ5: `route necessity → domain/association integrity → promise/destination integrity → installed/uninstalled/version fallback integrity → measurement-semantic integrity → lifecycle decision`.

Preserve: `owned URL exists ≠ app association verified`, `universal/app link configured ≠ every tap opens app`, `app opened ≠ promised value reached`, `deep link route ≠ attribution truth`, `Android 15 dynamic behavior ≠ Android ≤14 behavior`, `server dynamic rule ≠ permission beyond manifest scope`, `web fallback ≠ failure`, and `more deep links ≠ more organic growth`.
