## Latest validated addition — 143
Canonical finding: **MintTap 1.0.29 has a broader persistent-banner footprint than the first audit showed, and route identity alone is too coarse to define a safe monetization denominator. Ad eligibility must preserve substate/action boundaries, platform and widget lifecycle.**

Release-ref-qualified evidence confirms six screen-level placements so far: Home inline (P1), stock-detail fixed bottom (P2), distribution-by-period fixed bottom (P3), dividend-calendar fixed bottom (P4), transaction-history fixed bottom (P5), and yearly-ROC fixed bottom (P6). Calendar and yearly ROC explicitly exclude Browse mode; transaction history is signed-in; distribution-by-period has no screen-level browse exclusion evidenced in the audited source. The shared fixed-bottom and Home abstractions also map to web AdSense when configured, so mobile AdMob and web AdSense must remain separate measurement paths even when the Flutter placement identity is shared.

The new material risk is task-boundary drift: transaction history is a record-management/add-edit gateway and yearly ROC can launch tax-adjustment entry. A persistent banner can therefore remain present while the user's job changes from passive review to consequential financial/accounting action. BF eligibility must be defined as `route + substate + action boundary + platform + lifecycle/remount`, not merely `screen`. Direct `EditTransactionScreen` and `TransactionImportReviewScreen` do not import the audited shared ad-slot widgets in 1.0.29, supporting continued protection of direct edit/import workflows.

## Progress interpretation
A zero-cost channel is not successful because it generates clicks, followers or installs. A consequential financial claim is not trustworthy merely because it comes from an official-looking page. A Store treatment is not successful merely because a platform reports a better conversion number. Missing/censored evidence is not zero. An ad system is not successful because it maximizes impressions, eCPM or short-run revenue; success requires incremental reconciled revenue from natural eligible states without material degradation of core value. A code audit is not decision-grade unless it names the production/release ref, and **a route-level placement label is not a sufficient ad denominator when the user's task can cross from passive review into consequential edit, import or tax-adjustment intent.** Optimize qualified retained/reactivated specialist utility, evidence integrity, community trust and sustainable reconciled revenue—not content volume, top-of-funnel volume or raw ad inventory.
