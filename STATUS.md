## 052 — Controlled Activation Validation
`research/052_sparse_niche_controlled_activation_validation.md`

Small-N specialist usability testing is now explicitly separated from quantitative estimation. Roughly five target users is a high-efficiency qualitative starting point for discovering usability failures; it is not enough to estimate conversion or retention. MintTap should run iterative fresh-user rounds using sanitized Manual and Import fixtures.

Semantic first value is defined as a personalized portfolio result the participant can meaningfully interpret, not account creation, onboarding completion, transaction save, or import completion.

Validation gates:
`V0 instrumentable study → V1 route discovery → V2 first-value reachability → V3 result comprehension → V4 credible return reason → V5 controlled acquisition restart`

Severity promotes one clear S3 activation blocker, independently recurrent S2 friction, Store-promise contradiction, or specialist trust/compliance risk for remediation. These are product decision rules, not statistical-significance thresholds.

Apple native usage/retention remains downstream evidence: App Store Connect usage is opt-in dependent and privacy-thresholded; sparse cohorts may be unavailable. Qualitative observation, product telemetry, Store analytics and owner evidence must therefore remain separate evidence layers.

Operational artifact: `playbook/CONTROLLED_ACTIVATION_VALIDATION_TEMPLATE.md`.
