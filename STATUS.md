Ad monetization is evaluated by `value block → candidate boundary → exposure quality → interaction geometry → content integrity → format → downstream effect`, not format/eCPM/CTR alone. B1/B2/B3 remain protected; B4 is the first candidate boundary; B5 is strongest for non-interruptive inventory. Foreground callbacks do not create value. Friction-driven visible time is not quality inventory. Spatial adjacency/crossing corridors remain independent invalid-traffic risks.

073 adds a native-ad semantic gate. Native ads can match app UI, but specialist apps must preserve an explicit semantic firewall between advertising and high-trust product objects. C0–C5 classifies unknown, semantic collision, fragile attribution, visual/interaction mimicry, distinct native integration, and stable content-safe inventory. Native placement eligibility requires at minimum `B4/B5 + E4/E5 + I4/I5 + C4/C5`.

Google first-party native-ad documentation refreshed 2026-09-17 requires visible ad attribution and AdChoices, prohibits custom click-handler overlays within the native view, and emphasizes correct resource lifecycle. Internal rule is stricter: an ad must never plausibly read as MintTap portfolio/distribution/ROC/tax analysis or LogMate FlightRecord/calculated total/import/compliance/operational content. Accessibility, localization and responsive states must preserve attribution and separation. A default-device screenshot is insufficient evidence.

MintTap native-ad substitution/experimentation remains NOT ELIGIBLE because the existing Home placement still lacks the 069–072 production ledger. LogMate remains ad-ineligible until real specialist first value exists. Do not use native format as a shortcut around unresolved value or interaction evidence.
