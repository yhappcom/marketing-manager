## Latest validated addition — 239
Apple Custom Product Pages (CPPs) are usable as zero-cost intent-routing surfaces, not only paid-ad landing pages. Apple currently supports up to 70 CPPs per app, unique shareable URLs, localized screenshots/previews/promotional text, selected keywords from the latest approved app version, and optional reviewed deep links into matching app content on iOS/iPadOS 18+. Keyword assignment can cause a CPP to appear for a matching App Store search instead of the default product page; this is not a ranking guarantee.

CPP metadata requires review. App Analytics can separate CPP impressions/downloads/redownloads/conversion and downstream engagement/retention/proceeds, but CPP metrics appear only after at least five first-time downloads. Missing reporting below that threshold remains unknown, not zero. Apple's aggregate CPP conversion-uplift statistic is promotional platform-wide evidence and must not be treated as a MintTap/LogMate forecast.

EY0–EY5: `intent identity → material-difference integrity → keyword/link truth → destination continuity → sparse-measurement integrity → durable-value decision`.

Preserve: `CPP count ≠ segmentation quality`; `unique URL ≠ causal proof`; `keyword assignment ≠ ranking guarantee`; `platform benchmark ≠ app forecast`; `CPP conversion lift ≠ retained specialist value`; `missing analytics below threshold ≠ zero`; `deep link ≠ valid destination until reviewed and tested`.
