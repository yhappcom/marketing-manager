**Official platform guidance checked 2026-10-24:** Google AdMob *Recommended banner implementations* explicitly recommends **allocating fixed space before an ad loads**, because late layout shifts can cause accidental clicks, and recommends a non-clickable separator/buffer around interactive elements (https://support.google.com/admob/answer/6275335). *Discouraged banner implementations* warns about ads adjacent to interactive elements or sandwiched among app controls (https://support.google.com/admob/answer/6275345). Flutter banner guidance describes stable anchored-adaptive size during **refresh**, which does not prove this app's initial zero→loaded geometry is stable (https://developers.google.com/admob/flutter/banner). No fixed minimum dp separation or automatic violation threshold is inferred from these sources.
