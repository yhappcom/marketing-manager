## Route Promotion Gate

Before `route_candidate`, confirm:

- [ ] intended specialist audience is represented
- [ ] independent recurrence is C2+; C3 preferred
- [ ] not dominated by one viral/event thread without recurrence
- [ ] job is materially distinct from existing route(s)
- [ ] current/release-ready product truth supports the promise
- [ ] Store Proof Triad would genuinely differ
- [ ] at least one sustainable permission-safe source path exists
- [ ] traffic/strategic importance can support a decision
- [ ] maintenance/localization burden is justified

## Community Posting Gate

Before company-affiliated participation/linking:

- [ ] specific community rules checked recently
- [ ] promotional permission classified
- [ ] affiliation disclosure handled
- [ ] native answer is useful without requiring the link
- [ ] no repetitive/mass-post payload
- [ ] no unsolicited DM/chat outreach
- [ ] no unauthorized scraping/automation
- [ ] source/campaign tracking does not use deceptive redirects

## Evidence Rules

- One question is not a market segment.
- Multiple comments in one thread are not automatically independent recurrence.
- Owned/company-seeded community discussion is marked separately.
- Event bursts are not automatically evergreen demand.
- Do not store usernames/UIDs unless a concrete lawful operational need exists; this marketing registry normally has none.
- Search Console query data is incomplete because privacy anonymization/truncation exists.
- Community evidence supports hypotheses; downstream behavior is required for stronger validation.

Canonical progression:

`C1 isolated expression → C2 independent recurrence → C3 cross-surface corroboration → C4 behavioral validation → C5 durable economic validation`
