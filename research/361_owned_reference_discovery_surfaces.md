# Research 361 — Owned-Reference Discovery Surfaces Beyond Classic SEO

Date: 2026-10-01
Status: VALIDATED
Scope: MintTap, LogMate, reusable niche-app growth

## Why this is new

Research 299–300 established maintained owned references as durable answers to recurring specialist problems. This extension changes the discovery model: owned references should no longer be evaluated only by classic text-query SEO. Google Search now exposes additional zero-cost discovery and measurement surfaces that can matter to evidence-heavy niche apps.

## Authoritative platform changes

1. Google Search Console added web multimodal Search performance reporting on 2026-09-24. It covers searches using Lens, Circle to Search on Android, image uploads to Google Search, and Chrome “Search this image”; eligible sites can filter/export this traffic in Performance reporting.
2. Google Preferred Sources is available globally in all Google Search languages. A domain/subdomain selected by a reader can be more likely to appear in Top Stories and can receive a preferred badge; where supported, Preferred Sources can also surface in AI Mode and AI Overviews. Google provides a standard button and deeplink implementation.
3. Google’s 2026 documentation update log confirms that spam policies apply to generative-AI responses in Search. Therefore AI/visual discovery is not a justification for scaled, synthetic, or search-engine-first content.

## Operating conclusion

For specialist apps, an owned reference can create value through four distinct discovery modes:
- text query discovery;
- visual/multimodal discovery;
- reader-selected source preference;
- community/social citation that lands on the maintained reference.

Do not create separate content clones for each mode. Keep one canonical, evidence-maintained reference unless user intent or workflow materially differs.

## HX0–HX9 — discovery-surface contract

HX0 recurring specialist problem
→ HX1 canonical evidence-backed reference
→ HX2 text-search eligibility/indexability
→ HX3 visual asset has standalone explanatory value
→ HX4 visual context/alt/caption/page semantics preserve meaning
→ HX5 multimodal Search Console observability where traffic exists
→ HX6 preferred-source eligibility only when the site behaves like a genuine publication/source
→ HX7 native community/social citation only when it adds value
→ HX8 first/repeated specialist-value linkage
→ HX9 KEEP / IMPROVE-VISUAL / IMPROVE-DISCOVERY / HOLD-NO-EVIDENCE / RETIRE.

## MintTap application

High-value reference candidates such as ROC state/provenance, split/reinvestment reconstruction, and total-return methodology can contain compact tables, annotated timelines, or calculation diagrams when the visual itself clarifies the specialist problem. The purpose is comprehension first; multimodal discovery is a secondary benefit.

Do not manufacture ticker-image galleries or repetitive infographics merely to target Lens/image traffic. Do not infer app acquisition from Search impressions. Record Search discovery separately from attributable Store visit, first specialist value, and repeated specialist value.

Preferred Sources is worth evaluating only if minttap.app develops a maintained publication/reference identity with recurring authoritative updates. It should not be promoted merely as another acquisition CTA.

## LogMate application

For LogMate, useful visual reference assets could eventually explain import mappings, duplicate-resolution logic, Previous Total continuity, export integrity, or device/PWA boundaries. They must not expose user logbook data or imply capabilities not yet verified. Pre-launch product integrity remains prior to search-discovery optimization.

## Measurement

Maintain discovery modes separately:
- text Search impressions/clicks/query;
- multimodal Search impressions/clicks/query where available;
- community/social referral;
- Store/referrer evidence where available;
- first specialist value;
- repeated specialist value.

A new discovery surface is successful only when it yields useful specialist discovery or downstream value without degrading reference quality. Low/no multimodal traffic is not a reason to add decorative images.
