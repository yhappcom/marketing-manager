# Research 385 — Community Marketing: Link Omission Is a Trust Control, Not Lost Attribution

Date: 2026-10-03
Status: VALIDATED

## Why this matters

Sparse-niche apps cannot treat every useful community contribution as a referral opportunity. For specialist communities, the first optimization target is contribution eligibility and trust, not link capture.

Reddit's current official guidance is explicit on the underlying mechanics:
- authentic participation in communities of genuine interest is the baseline;
- business-link-heavy contribution frequency can create spam risk;
- community-specific rules and moderator judgment control what is unwanted;
- repeatedly attaching a community/product link to comments or posts is considered spam in Reddit's own community-growth guidance;
- organic mentions are appropriate when relevant to an existing conversation.

Therefore, a no-link native answer is not an uninstrumented failure. It is a distinct marketing treatment that can preserve eligibility, establish domain credibility, reveal specialist language, and create later branded/search demand that Store attribution may record as Search rather than referral.

## New operating principle

**Earn the right to link. Do not make the link the unit of contribution.**

For each community interaction, decide independently:
1. Is there a real specialist problem we can answer?
2. Can the native answer be complete without leaving Reddit?
3. Does the community permit relevant self-reference or links?
4. Does an external reference add durable evidence/methodology that cannot be conveyed reasonably in the native answer?
5. Is affiliation disclosed where material?
6. Would omission of the link materially reduce user value?

If 6 is no, omit the link.

## IL0–IL9 — Link-Admission Contract

IL0 specialist problem fit  
→ IL1 current community-rule check  
→ IL2 complete native answer  
→ IL3 material affiliation disclosure  
→ IL4 external-reference incremental-value test  
→ IL5 repetition/business-link exposure check  
→ IL6 community/account trust state  
→ IL7 link admission: OMIT / PERMIT / ASK-MOD / OWNED-REFERENCE-ONLY  
→ IL8 contribution evidence + platform attribution kept separate  
→ IL9 downstream first/repeated specialist value when observable.

## Measurement consequence

Do not compare “linked post installs” against “unlinked post installs” as though both expose the same eligible audience and trust state. Link presence can itself alter moderation/filtering, user reception, and future account eligibility.

Maintain three ledgers:
- **Contribution ledger:** problem answered, native completeness, qualitative response, recurring language, corrections, moderator outcome.
- **Attribution ledger:** Store campaign/referrer/search/browse evidence that the platform actually observed.
- **Product-value ledger:** first specialist value, repeated specialist value, sustainable non-intrusive monetization.

No causal bridge is asserted unless evidence supports it.

## MintTap

For YieldMax discussions, answer the actual ROC/distribution/return-methodology problem natively first. Do not append MintTap or r/MintTapforYieldMax mechanically. A link is admitted only when it adds maintained data, methodology, reconstruction, or another durable reference that materially improves the answer and the community permits it.

Ticker variation alone does not justify repeated linking. Repeated TSLY/CONY/MSTY/NVDY answers should consolidate around the recurring job/problem, not become four promotional funnels.

## LogMate

Pilot communities have higher professional-trust sensitivity. Migration/import, duplicate handling, Previous Total, export integrity, and PWA/offline questions should be answered as professional workflow problems first. Before launch, no product link is needed merely to “seed awareness.” A future LogMate reference is admitted only when it is permitted and materially improves the professional answer.

## Reusable niche-app rule

Community marketing sequence:

specialist problem → useful native contribution → trust/permission → optional durable reference → observed attribution → first/repeated product value.

Not:

product → link → distribution → clicks.

## Sources

- Reddit Help, “Spam,” current guidance accessed 2026-10-03: authentic participation, caution when contributions primarily link to a business, and community-specific moderator judgment.
- Reddit Help, “Growing your community,” updated 2026-05-28: organic relevant mentions are acceptable; adding a community link to all comments/posts is considered spam; mass messaging is spam.
- Reddit Help, “How do I keep spam out of my community?”, updated 2026-04-02: promotional content is not inherently spam, but communities can prohibit it and some use their own promotional conventions.
- Apple App Store Connect Analytics, Campaign Links: campaign links can observe product-page views/downloads/usage/sales, but this observed attribution should remain separate from community contribution evidence.
