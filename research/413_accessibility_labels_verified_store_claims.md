# Research 413 — Accessibility Labels Are Verified Store Claims

Validated: 2026-10-04

Apple Accessibility Nutrition Labels should be treated as evidence-bearing Store claims, not promotional badges.

## JV0–JV9
common-task inventory → device-family matrix → feature criteria → real workflow verification → blocking-bug check → claim decision → accessibility reference scope → publish/update → Store observation → regression monitoring.

States: VERIFIED / PARTIAL-NOT-CLAIMABLE / BLOCKED-BUG / NOT-APPLICABLE / UNKNOWN / PUBLISH / UPDATE / RETIRE.

## Validated findings
Apple says labels appear on product pages on OS 26-era Apple platforms and are device-specific. To indicate support, users must be able to complete all common tasks with the relevant accessibility feature under Apple's evaluation criteria. Material accessibility bugs that change that answer mean support should not be claimed. An app-specific Accessibility URL can explain additional support and limitations. Apple also states that accessibility capabilities can contribute to search relevance when users include those capabilities in search queries. Reporting begins voluntarily but Apple says it will become required over time for new-app and update submissions.

## Operating rule
Never claim support because one screen works. Evaluate the actual common-task set per device. Search/discovery benefit is downstream of verified capability, not a reason to overclaim.
